# 4ek-lis
Чак-лист для челленджей и хешмобов

Read-nur-Me
Конструктор чек-листа для загрузки категорий и заданий к ним. 
Контент сохраняется в файл JSon
Открывается в блокноте. 
В блокноте же открывается файл "публичная часть чек-листа", JSon вставляется в размеченную часть в кодах. 
Публичная часть выкладывается репозиторий для трансляции в GH Pages.
В качестве счетчика подключается Гугл-таблица "Контакты с 4ek-Lis" с -> расширением -> AppScript (код для него в файле App).
Гугл отдает ссылку, вставляем ее в Конструктор.
